# ECB end-2024 exposure snapshots

These are the BSI and SHSS source extracts used by `R/data/exposures.R`. The original query URLs and retrieval hashes are in `retrieval_manifest.json`. Monetary observations are EUR million; the reconstruction converts them to EUR billion. December monthly and fourth-quarter stocks are alternative observations of the same reference date, never additive positions.

The root `data/README.md` explains institutional coverage, transformations and redistribution terms.
