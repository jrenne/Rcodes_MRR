# Working repository

Rcodes_MRR is the sole active repository for this study. Make code and documentation changes here. Copies of Rcodes_BIS under ../archives are frozen historical records and must not be updated or used as a source for routine synchronization.

The local manuscript is in manuscript/paper and is excluded from GitHub, together with private_data and generated outputs. Rscript main.R reproduces the results and copies publication assets into the local manuscript when it is present. Rscript scripts/run_tests.R validates the default calibration. The public replication archive excludes the manuscript and private data.
